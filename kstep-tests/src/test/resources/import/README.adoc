= Import fixtures (ADR-0030)

STEP files cannot carry provenance comments here: the Part 21 reader used for identifier enrichment does not
support `/* */` comments, so a comment would silently disable that enrichment. Provenance lives in this file.

|`external-ref.step` |`box-20x30x40.step` plus a `DOCUMENT_FILE` entity (`#9998`); must be rejected before OCCT sees it.
|`cyclic-nauo.step` |`kstep export export-assembly-geometry.kstep.kts` plus a reverse `NEXT_ASSEMBLY_USAGE_OCCURRENCE`
